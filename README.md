# ILLUSIONARY // ARCHIVE 001

A six-stage, browser-based puzzle experience.

Begin at **[A SIGNAL WITHOUT AN ORIGIN](./index.html)**.

The archive uses encoded transmissions, a recovered witness statement, and a line/column extraction. Each decoded address leads to the next stage.

## Publishing

This repository is prepared for GitHub Pages.

1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then save.
4. Open the Pages URL once GitHub finishes publishing.

The site is static and requires no build command.

## Note

Puzzle gates are client-side and are intended for an informal ARG, not for protecting private information.
